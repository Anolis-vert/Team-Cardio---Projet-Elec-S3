# Team-Cardio---Projet-Elec-S3

Le cardio-fréquencemètre est un appareil qui permet de mesurer la fréquence cardiaque, c’est-à-dire le nombre de pulsations du cœur par minute. Il est utilisé à des fins médicales mais également sportives, afin de mettre au point des programmes d’entrainement personnalisés. Le premier cardio-fréquencemètre a été inventé en 1977 par un Professeur finlandais, Seppo Säynäjäkangas qui a par la suite fondé Polar Electro.


Deux types de capteurs permettent de mesurer la fréquence cardiaque :
  • les capteurs ECG (électrocardiographie), plutôt utilisés dans le domaine médical, qui mesurent le bio-potentiel généré par les signaux électriques qui contrôlent l’expansion et la contraction des cavités cardiaques ;
  • les capteurs PPG (photo-pléthysmographie), plutôt utilisés dans le domaine sportif, qui mesurent le volume sanguin contrôlé par l’action de pompage du cœur.

  
Le but de ce premier projet est d’acquérir des compétences techniques en concevant, fabriquant et testant un cardio-fréquencemètre, tout en apprenant à travailler en groupe en appliquant une méthodologie de projet cycle en V.
